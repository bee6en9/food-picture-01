# Spicy tantanmen, mid-pull

Entry for make.fun `food-picture-01` — make the best-looking food picture.

A close-up of a bowl of spicy tantanmen ramen: chopsticks lifting a tall
tangle of glossy noodles slicked with red chili oil, a halved jammy egg
with a golden yolk dripping, minced pork, bok choy and sesame, steam
rising through warm moody light on a dark wooden table.

The program (`main.py`, Python 3.13 standard library only) writes the
embedded JPEG to `$MAKEFUN_OUTPUT_DIR/entry.png`. It runs twice and
writes byte-identical output both times.
